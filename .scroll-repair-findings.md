Scroll repair findings, 2026-08-22

The mobile project carousel had `touch-action: pan-x`, which prevented vertical page panning when a finger started on the project card. The compatibility fallback also used `overflow: hidden` on the entire page shell, which could trap document flow on engines without `overflow: clip`.

The repair allows `pan-x pan-y` inside the horizontal carousel so browsers can axis-lock horizontal swipes while retaining vertical page scroll. The shell fallback now uses visible overflow, while `body.rebuild-body` clips only the horizontal axis. The modal-only body overflow lock remains unchanged.

Full-page 390px and desktop 1440px captures show the document continues through the project section and the desktop composition remains intact.
