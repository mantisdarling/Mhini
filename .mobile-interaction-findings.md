Mobile image fade and project carousel, 2026-08-22

Added a load-aware ResponsiveImage wrapper. The image frame stays allocated while the selected desktop or mobile source loads, then the image gains is-loaded and fades in through opacity. If a mobile source errors, the wrapper removes the mobile source and retries the desktop source. Reduced-motion users receive an effectively instant reveal.

At 390x844, the phone capture shows the cinematic imagery, the project section is a horizontal touch track with a deliberate next-card peek, and the page remains within the viewport without horizontal body overflow. At 1280x720, the project archive remains the original closed multi-column grid and all desktop imagery remains visible. The project archive has a focusable region with carousel semantics and each card remains keyboard-openable.
